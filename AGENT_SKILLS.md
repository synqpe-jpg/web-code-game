## 📌 Enforced Instructions
All frontend UI/UX development in this project must strictly comply with [`.antigravity/instructions.md`](file:///c:/4%20Antigravity%20all/13%20web%20code%20game/.antigravity/instructions.md) and the comprehensive design intelligence from **UI/UX Pro Max**:
1. **Design System & Palettes**: Purpose-driven palettes with strict semantic tokens (CSS variables / Tailwind configs).
2. **Anti-"AI Generic Slop"**: No random low-contrast purple neon slop, no emoji icons, no raw hex hardcoding.
3. **Typography**: Cohesive font pairings (Headings + Body) with proportional line heights.
4. **Micro-interactions**: Hover, active, focus-visible states, touch target min 44x44px.
5. **Quality Gate**: WCAG 2.1 AA accessibility, contrast >= 4.5:1, responsive across 375px–1440px+.
